# Fictional dataset

Run `python3 synthetic_data/catalog.py` to regenerate the checked-in scenarios. The catalog contains 78 challenge scenarios plus one Harbour Repair example, with independent expected fields, known gaps, replies and expected outputs. Scenario attachment content is packaged as actual PDFs or text files on seeding. All names, street addresses and messages are fictional. All email domains are reserved and phone numbers use the fictional 555-0100 through 555-0199 range.
